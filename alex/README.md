# Driver's Guide to Fixing Posture

An interactive web guide for drivers suffering from Upper Crossed Syndrome, created by Coach Pete Ryan.

## Features

- **Interactive Muscle Diagram**: Click on muscle groups to learn about tight vs weak muscles
- **Mobile-Responsive Design**: Works perfectly on phones, tablets, and desktops  
- **Exercise Toggle**: Switch between "In The Car" and "At Home" exercises
- **Professional Branding**: Matches Coach Pete Ryan's brand identity
- **Simple Language**: Easy to understand for non-native English speakers

## How to Deploy on GitHub Pages

1. **Create a new repository** on GitHub (e.g., `posture-guide`)
2. **Upload all files** from this folder to your repository
3. **Enable GitHub Pages**:
   - Go to repository Settings
   - Scroll to "Pages" section
   - Select "Deploy from a branch"
   - Choose "main" branch
   - Click "Save"
4. **Your site will be live** at: `https://yourusername.github.io/posture-guide/`

## Files Included

- `index.html` - Main webpage (single file, no dependencies)
- `*.png` - Exercise illustrations and diagrams
- `README.md` - This file

## Technical Details

- **Single File Design**: Everything (HTML, CSS, JavaScript) is in one file
- **No External Dependencies**: Works offline and loads fast
- **Mobile-First**: Optimized for touch devices
- **Cross-Browser Compatible**: Works on all modern browsers

## Customization

To customize the content:
1. Edit the `index.html` file
2. Replace images with your own (keep same filenames)
3. Update the branding links to point to your website

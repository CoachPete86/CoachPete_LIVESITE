App Architecture Overview

The NeuroFit mobile app is designed as a comprehensive brain-body training companion that delivers personalised workouts, tracks progress, and integrates with the broader NeuroFit ecosystem.

Core Value Proposition: The only fitness app that trains your brain and body simultaneously, using AI to personalise challenges based on both physical and cognitive performance metrics.

User Journey & App Flow

Primary User Flows

Flow 1: New User Onboarding

User Story: "As a new user, I want to quickly understand how NeuroFit works and get started with a personalised program."

Journey Steps:
1. App store download and install
2. Welcome screen with value proposition
3. Account creation (email/social login)
4. Comprehensive fitness and cognitive assessment
5. Goal setting and preference selection
6. Equipment availability check
7. First workout recommendation
8. Guided first session with tutorial overlays
9. Post-workout feedback and program adjustments

Flow 2: Daily Workout Experience

User Story: "As a regular user, I want to quickly access my daily workout and have a seamless training experience."

Journey Steps:
1. App launch with personalised dashboard
2. Today's workout preview and readiness check
3. Warm-up phase with movement prep
4. Main workout with real-time form feedback
5. Cognitive challenges integrated during exercises
6. Cool-down and recovery protocols
7. Session summary and progress updates
8. Next workout preview and scheduling

Core Feature Specifications

P1 AI-Powered Form Analysis

Technical Implementation:
  • Computer Vision Engine: MediaPipe Pose for real-time skeletal tracking
  • ML Model: Custom TensorFlow Lite model trained on 10,000+ exercise videos
  • Processing: On-device inference for privacy and speed
  • Feedback System: Real-time audio/visual cues for form corrections
Feature Requirements:
• Detect 15 key body landmarks in real-time
• Provide instant feedback for common form errors
• Score movement quality on 0-100 scale
• Generate personalised form improvement recommendations
• Track form consistency over time
• Work in various lighting conditions and camera angles
Success Metrics: >85% accuracy in form detection, <200ms feedback latency, >90% user satisfaction with feedback quality

Frontend Architecture

React Native Implementation

  • Framework: React Native 0.72+ with New Architecture
  • State Management: Redux Toolkit with RTK Query
  • Navigation: React Navigation 6.x with deep linking
  • UI Library: Native Base + custom components
  • Animations: React Native Reanimated 3 for smooth 60fps

Backend Architecture

AWS Infrastructure

  • API Gateway: GraphQL with AWS AppSync
  • Authentication: Amazon Cognito with multi-factor auth
  • Database: Amazon DynamoDB with global tables
  • File Storage: Amazon S3 with CloudFront CDN
  • ML Pipeline: Amazon SageMaker for model training
